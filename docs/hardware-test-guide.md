# 실기 테스트 가이드

코드와 단위 테스트로는 확인할 수 없어 기기를 들고 직접 봐야 하는 항목이다. 위에서부터 하면 되고, 각 항목은 따로 해도 된다.
USB 를 꽂아 두면 도우미 기록(`~/.llm-deck/companion.log`)에 기기 로그가 남는다. 배터리·Wi-Fi 항목은 기기 로그가 PC 로 오지 않으므로 화면으로 판단한다.

| # | 항목 | 하는 법 | 통과 기준 |
|---|------|---------|-----------|
| 1 | 미러링 기기 화면의 마이크 표시 | USB 로 미러링을 켜고 기기 화면을 본다 | `USB` 글자 바로 오른쪽에 마이크 모양이 있고, 색이 상태줄 표시와 같다 |
| 2 | 기기 마이크 인식 | 미러링 창에서 상태줄의 마이크 표시를 누른다 | 창 맨 위에 `쓰는 중: 기기 마이크` 가 나온다. 다른 글이면 납땜·배선부터 확인한다 |
| 3 | 기기 마이크 녹음 | 기기 화면을 두 번 탭하고 5초쯤 말한 뒤 다시 두 번 탭한다 | 말한 내용이 글로 입력된다. 뭉개지거나 비어 있으면 `>> 14` 게인 문제일 수 있다 |
| 4 | Wi-Fi 미러링 | USB 를 뽑고 미러링 창을 연 채 10분 둔다. 신호가 약한 곳에서도 한 번 해 본다 | 화면이 계속 갱신된다. 멈추면 멈춘 시각과 멈춘 시간을 적어 둔다 |
| 5 | USB 드라이브 | 빠른 설정에서 `USB 드라이브` 를 누른다. 끝나면 기기 화면에서 나간다 | Mac 에 SD 카드가 나타나 파일이 열리고, 나가면 재시작한 뒤 도우미가 다시 붙는다 |
| 6 | 기기에서 QR 읽기 | 카메라 스캔을 켜고 QR 을 네모 안에 20cm 이상 떨어뜨려 비춘다. USB 를 뽑고도 한 번 한다 | 화면에 `QR: 내용` 이 나온다. 기록의 `[qr]` 줄에 걸린 시간이 남는다 |
| 7 | 들어 올려 깨우기 | 설정 > 배터리 > `들어 올려 깨우기` 를 켠다. 화면이 꺼진 뒤 기기를 든다 | 화면이 켜진다. 책상을 두드리거나 타자를 칠 때는 켜지지 않는다 |
| 8 | 배터리 절약·CPU 절전 | USB 를 뽑고 `배터리 절약` 을 켠 뒤 만지지 않는다 | 1분 뒤 어두워지고 3분 뒤 꺼진다. 만지면 바로 켜진다 |
| 9 | 자동 꺼짐과 깨우기 | 배터리로 `자동 꺼짐` 을 켜고 20분 둔다. 그다음 BOOT 를 누른다. 7번을 켠 채로 한 번 더 해서 이번에는 기기를 든다 | 꺼졌다가 BOOT 로 켜지고, 7번을 켰으면 들어서도 켜진다 |
| 10 | 블루투스 키보드 | 설정 > 블루투스 > `키보드 모드` 를 켠다 (재시작). PC 나 휴대폰에서 `LLM Deck Keys` 를 페어링하고 리모컨 페이지의 버튼을 누른다 | 키가 입력된다. 끝나면 키보드 모드를 끄고 도우미가 다시 붙는지 본다 |

9번과 10번은 도우미 연결이 잠시 끊긴다. 결과는 항목 번호와 통과·실패, 실패면 본 그대로 적어 주면 된다.
