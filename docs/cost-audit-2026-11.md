# 2026년 11월 S3 비용 표시 조사

> 이 문서는 최초 원인 조사 기록이다. 후속 오너 요구에 따른 최종 동작은 [공급자 비용 및 사용률 환산 변경](provider-costs-and-usage-value.md)을 따른다. 제품의 비용 페이지에서는 이 문서의 로컬 월간 환산액을 더 이상 표시하지 않는다.

**$1,031.38은 결제액이 아니라 이 PC의 Claude 대화 기록을 API 가격으로 환산한 추정치다.** 구독으로 사용한 응답도 들어간다. 이 숫자로 11월에 $1,031을 실제 결제했다고 판단할 수 없다. 또한 Sonnet 5.5 캐시 읽기 단가가 두 배로 들어간 오류가 있었다.

조사일: 2026-11-28, PC 시간대 Asia/Seoul(KST). 새 worktree의 기준 커밋은 `dec69b0`이며 실행 중 도우미와 별도로 조사했다. 원본 로그·설정·실행 중 서비스는 변경하거나 재시작하지 않았다.

## 재현 및 원본 숫자

기기 화면 자체를 촬영한 것은 아니며, 기기로 보내는 기존 `api_cost.collect()`의 페이지 payload에서 11월 Claude `$1,031.38`을 재현했다. 소수점이 빠지거나 통화를 환산한 값이 아니며, USD를 두 자리로 반올림한 것이다.

15:58~15:59 KST 로컬 원천 로그 집계. 이후 **2026-11-28 15:57:59.999999 KST cutoff**로 사용량 행을 제한해 같은 값을 별도로 재현했다(S31 조사와도 일치).

| 모델 | 고유 응답 | 기존 API 환산 USD |
| --- | ---: | ---: |
| Claude Opus 5.5 | 11,697 | 922.84100480 |
| Claude Sonnet 5.5 | 2,166 | 108.53689230 |
| Claude Haiku 5.5 | 4 | 0.00605046 |
| **Claude 합계** | **13,867** | **1,031.38394756** |

출처는 실행 중 도우미의 기본 `~/.claude/projects/**/*.jsonl`의 assistant `message.usage`다. 기간은 **2026-11-01~11-28 KST에 기록된 응답**이며 이전 달을 누적하지 않는다. `message.id + requestId`로 중복을 제거한다. 27,682개의 usage 줄 중 13,815개는 중복이고 위의 응답 수에는 한 번씩만 들어갔다. 중복 usage가 서로 다른 경우가 2줄 있어 첫 조각/파일 탐색 순서에 따라 값이 달라지는 문제도 확인했다.

최초 usage 스냅샷 기준 토큰 합계(중복 제외): 입력 31,773, 출력 11,640,532, 캐시 읽기 2,250,526,374, 캐시 쓰기 51,611,908. fast 표시 응답은 0개였다. 캐시 읽기는 요청마다 재사용한 문맥을 세므로 대화 원문의 서로 다른 글자 수와 다르다. 캐시 토큰을 일반 입력 단가로 다시 과금하는 계산은 하지 않는다.

Codex는 `~/.codex/sessions/**/*.jsonl`의 요청별 `token_usage_record.payload.usage`를 `response_id`로 중복 제거한다. 누적 `total_token_usage`를 합산하지 않으며 reasoning을 output에 다시 더하지 않는다. 15:59 KST 기준 고유 291응답, 모델 `gpt-6.1-sol`, 기존 환산치는 `$5.1193612`였다. **$1,031은 Claude 열의 값이지 Claude+Codex 전체 합계가 아니다.** 기록이 계속 추가되고 있어 시점마다 금액이 달라진다.

## 공급자 비용과 결제액

15:59 KST에 실행 중 체크아웃의 설정에서 키를 메모리로만 읽고 공급자 비용 API를 읽기 전용으로 조회했다. 키/원문/응답 ID는 출력하거나 보고서에 저장하지 않았다.

| 공급자 | 조회 결과 | 확인 범위 |
| --- | --- | --- |
| OpenAI | **$0.58220476 USD** | `GET /v1/organization/costs`, 2026-11-01 00:00 UTC~2026-11-28 06:59 UTC, 반환된 27개 일별 bucket 합계, currency=`usd` |
| Anthropic | **HTTP 401** | `GET /v1/organizations/cost_report`, 같은 UTC 기간, 인증 거절로 사용액 미확인 |

OpenAI의 값은 해당 Admin 키가 속한 조직의 API 비용 데이터이며 카드 결제액·구독료·최종 청구서·세금·다른 조직의 사용액은 확인하지 않았다. 오늘의 미집계 사용액이 뒤늦게 반영될 수 있다. Anthropic은 유효한 권한으로 재조회해야 하며 $0이라고 판단할 수 없다. 구독 포함 사용과 별도 과금의 분리는 로컬 usage에 결제 상태가 없어서 개별 응답별로 확인할 수 없다.

[OpenAI Costs 공식 문서](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs)의 `amount.value`는 통화 단위 값이고, [Anthropic Cost API 공식 문서](https://platform.claude.com/docs/en/manage-claude/usage-cost-api)의 `amount`는 센트 문자열이다. 기존 수집기의 OpenAI USD 합산/Anthropic 100 나누기는 맞았다. 양쪽 `has_more`/`next_page` 처리를 재현 테스트로 검증했다. 크레딧 날짜 때문에 이전 달부터 조회하더라도 월 합계는 해당 월만 더한다.

## 원인과 수정

1. 화면에서 API 환산치 설명이 빠져 있었다. 표시 제목을 **API Estimate**로 바꾸고 “API 환산 추정 · 청구액 아님 / 구독 사용 포함”을 항상 표시한다. 공간 확보를 위해 큰 합계 headline을 제거하고 회사별 오늘/월 표는 유지한다. 내부 페이지 식별자 `API Cost`는 유지한다.
2. Sonnet 5.5 캐시 읽기가 `$0.20/MTok`으로 잘못 설정되어 있었다. [공식 최신 가격표](https://platform.claude.com/docs/en/about-claude/pricing)(2026-11-28 확인)의 **$0.10/MTok**으로 수정했다. 완성된 usage 기준 해당 모델의 캐시 읽기 303,317,089토큰에서 **$30.33170890**가 과대 환산됐다.
3. 같은 응답의 스트리밍 조각/재개 복사본이 서로 다른 usage를 가지면 파일 순서에 따라 값이 달라졌다. 두 응답의 초기 output 6/4 대신 완료 output 2,431/2,283을 선택하면 기존 단가 기준 **$0.04704000**가 더해진다. 합산하는 대신 알려진 비용이 가장 큰 스냅샷 하나와 최초 날짜를 유지해 재수집 순서나 복사 시점에 따라 금액/월이 달라지지 않게 했다. 원본 데이터는 바꾸지 않았다.
4. 공급자 API는 UTC 기준인데 Billing 표의 월 이름은 PC 현지 시간이었다. 월 경계에서 다른 달의 금액처럼 보일 수 있어 Billing 월 이름/시각도 UTC로 맞추고 “API 사용액 · 결제 내역 아님”을 추가했다. 로컬 Estimate는 PC 현지 시간 기준이다.
5. 읽기 전용 재현 도구 `companion/audit_api_cost.py`를 추가했다. 모델별 고유 응답 수와 환산 합계만 출력하며 키나 원문은 읽거나 출력하지 않는다.

**고정 cutoff의 정확한 교정: $1,031.38394756 + $0.04704000 − $30.33170890 = $1,001.09927866**. 교정 후 모델별 금액은 Opus $922.84100480, Sonnet $78.25222340, Haiku $0.00605046이다. 이것 역시 결제액이 아니다.

cutoff 없이 수정 후 16:02 KST 집계는 Claude `$1,001.27663006`(Opus 11,702응답), Codex `$5.34087320`(306응답)이었다. 최초 조사보다 응답이 늘었으므로 다른 시점의 달러 차이를 모두 가격 수정 효과로 해석하면 안 된다. 단가는 현재 표에 따른 추정치이며 과거 할인·계약·지역·서비스 티어·도구 비용까지 재구성한 최종 청구 계산이 아니다. 알 수 없는 모델은 금액에서 제외하고 화면에 알린다.

## 실행 중 인스턴스와 재현

실행 중 S3 도우미의 cwd는 기본 체크아웃 `esp32_S3/companion`이고 `CLAUDE_CONFIG_DIR`/`CODEX_HOME` 환경변수가 없다. 반면 Orca worker 및 새 terminal은 프로필별 환경을 가질 수 있다. 기본 로그 경로를 명시한 결과로 비교했으며, 기본 체크아웃의 기존 collector 소스는 작업 시작 당시 새 worktree와 동일했다. 메모리에 이미 로드된 코드나 물리 기기의 현재 화면까지 확인한 것은 아니다.

```sh
python3 companion/audit_api_cost.py --month 2026-11 \
  --claude-root "$HOME/.claude/projects" \
  --codex-root "$HOME/.codex/sessions"
```

다른 프로필을 조사하려면 해당 경로를 명시한다. 이 도구는 현재 남아 있는 로그만 셀 수 있어 삭제된 기록·다른 PC·다른 프로필의 전체 사용량을 보증하지 않는다.

- 최종 전체 companion 테스트: **651 passed, 2 skipped**, 113.94초. PR/커밋은 PR 설명에 기록한다.
- **현재 실행 인스턴스에 미적용**이다. 이 worktree의 코드를 병합한 뒤 허용된 배포 시점에 도우미를 다시 실행해야 화면이 바뀐다. 이 작업에서는 서비스 중지/재시작·merge를 하지 않는다.
- 남은 외부 확인: Anthropic 유효 Admin 인증, 공급자 청구서/구독 결제 내역, 비용 API 지연 반영, 실제 기기 배치 확인.
