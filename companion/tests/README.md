# 테스트
기기 없이 PC 에서 도는 자동 테스트입니다 (사진·동영상 받기, 프레임, ORCA 빠른 답, 키워드 입력, 사용량 계산).
`companion/` 폴더에서 `uv run pytest -q` 로 실행합니다 (실제 orca·claude 를 부르지 않고, 임시 폴더만 씁니다).

C++ 컴파일러와 PlatformIO 의 ArduinoJson 헤더가 있으면 펌웨어의 실제 수신 큐·명령 기록 코드도 PC에서 컴파일해 실행한다. 큐 포화, 할당 실패, 응답 크기 제한, 실행 전/후 저장 실패, 재부팅 후 중복 차단, 오래된 ID와 변조된 본문을 검증한다. Python 테스트는 ACK 유실·도우미 재시작·기기 재시작·서명 변조를 가짜 통신으로 확인하며 실제 장치를 조작하지 않는다.
