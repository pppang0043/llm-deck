LLM Deck PC 도우미 (Windows)
============================

LLM Deck 기기에 사용량을 보내고, 기기와 PC 를 이어 주는 프로그램입니다.
로그인할 때 자동으로 켜지고, 작업 표시줄 오른쪽 아래(트레이)에 LLM Deck 아이콘이 생깁니다.
아이콘을 누르면 미러링 창이 열리고, 오른쪽을 누르면 메뉴(미러링 열기, 항상 위, 도우미 다시 시작, 기록 보기, 종료)가 나옵니다.


누를 파일
---------
  install.cmd    설치 (고친 뒤 다시 켤 때도 이것)
  uninstall.cmd  제거
  config.cmd     설정(app\config.toml)을 메모장으로 연다. 고친 뒤 install.cmd 다시 실행
  INSTALL.txt    설치 방법 (용량이 적을 때, 음성 인식 모델, 회사 PC)
  mirror.cmd     기기 화면을 작은 창으로 보고 눌러서 조작 (USB·Wi-Fi 연결일 때)
                 트레이 아이콘이나 시작 메뉴의 "LLM Deck" 으로도 엽니다. 아래 "미러링" 참고.
  app 폴더       도우미 본체. 건드리지 않아도 됩니다.


설치
----
설치 방법은 INSTALL.txt 에 있습니다. (준비, 설치 순서, 용량이 적을 때 저장 위치 바꾸기, 음성 인식 모델 설치, 제거)
짧게: 이 폴더를 지우지 않을 곳에 두고 install.cmd 를 더블클릭합니다.

기기와는 USB 케이블, 같은 Wi-Fi, 블루투스 순으로 되는 것에 알아서 연결합니다.
회사처럼 Wi-Fi 를 쓸 수 없는 곳에서는 블루투스로 연결합니다.
블루투스는 PC 블루투스를 켜 두기만 하면 됩니다. (Windows 에서 따로 페어링하지 않습니다)
Wi-Fi 와 블루투스는 처음 한 번 USB 케이블로 연결해야 쓸 수 있습니다. 그때 받은 인증 키로 서명해서,
키가 없는 남의 PC 는 기기를 조작하지 못하고 가짜 기기도 이 PC 를 조작하지 못합니다.


저장 위치
---------
  사진     사진\LLM Deck
  동영상   비디오\LLM Deck   (.mov 가 안 열리면 VLC 로)
  기록     C:\Users\내이름\.llm-deck\companion.log
  설정     app\config.toml   (config.cmd 로 열어 고친 뒤 install.cmd 다시 실행)

여러 PC 의 한도 사용률은 설정의 gist 로 함께 봅니다 (미리 채워 둠). 받기만 할 때는 할 일이 없고,
이 PC 의 값을 올리려면 GitHub CLI 로그인(gh auth login -s gist)이 필요합니다.


미러링
------
기기 화면을 PC 창으로 보고, 마우스로 눌러서 기기를 조작합니다. 도우미가 켜져 있고
기기가 USB 나 Wi-Fi 로 연결되어 있어야 합니다. (블루투스로는 안 됩니다)
기기가 USB 나 Wi-Fi 로 새로 연결되면 창이 저절로 열립니다. (잠깐 끊겼다 다시 붙거나 창이 이미 열려 있으면 그대로 둡니다.
끄려면 config.toml 의 [mirror] 에 auto_open = false)

  누르기·끌기   마우스 왼쪽
  위아래 밀기   마우스 휠, ↑↓
  좌우 밀기     ←→
  홈            Esc

창에서 마우스 오른쪽을 누르면 메뉴가 나옵니다.
  항상 위       다른 창 위에 늘 떠 있게 합니다. 처음에는 켜져 있습니다. (트레이 메뉴에도 있습니다)
  1배·2배·3배   창 크기. 기기 화면 1점이 PC 화면 1점인 1배가 기본입니다.
                Windows 배율이 125%·150% 라서 작게 보이면 2배로 바꿉니다.
  홈 / 닫기
고른 것은 다음에 열 때도 그대로입니다.

창을 닫아도 도우미는 계속 돕니다. 도우미까지 끄려면 트레이 메뉴의 "종료" 를 누릅니다.

도우미 앱은 이 PC 의 Python(pythonw.exe)으로 돌아서 따로 만드는 exe 가 없습니다.
설치 중 [6/7] 에서 "건너뜁니다" 가 나오면 (Python 에 tcl/tk 가 없을 때) 도우미는 트레이 아이콘 없이 돌고,
mirror.cmd 가 대신 브라우저로 엽니다. 주소는 늘 http://127.0.0.1:4013/ 이라 즐겨찾기해 둬도 됩니다.
브라우저에서는 처음에 "맞춤" 으로 열려 창 크기에 맞춰 화면이 커지고 작아집니다. (1배·2배·3배로 바꿀 수 있습니다)


PC 용량이 부족할 때
-------------------
app\config.toml 의 [storage] 에 음성 인식 모델·설치 부품 보관함을 둘 폴더를 적을 수 있습니다.
INSTALL.txt 의 "4. 저장 위치 바꾸기" 를 보세요.


음성 질문이 안 될 때
--------------------
- "Windows 가 마이크를 막았습니다"
    Windows 설정 > 개인 정보 및 보안 > 마이크 에서
    "마이크 액세스" 와 "데스크톱 앱이 마이크에 액세스하도록 허용" 을 둘 다 켭니다.
- "PC 에 마이크가 없습니다"
    헤드셋·웹캠 마이크를 꽂으면 30초 안에 다시 켜집니다.
- "음성 질문 부품을 켜지 못했습니다" (설치할 때)
    https://aka.ms/vs/17/release/vc_redist.x64.exe 를 설치하고 install.cmd 를 다시 실행합니다.
- "음성 인식 모델을 불러오지 못했습니다" (회사망이 막을 때)
    모델을 직접 받아 넣습니다. INSTALL.txt 의 "5. 음성 인식 모델 설치" 방법 B 를 보세요.
